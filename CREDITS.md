# Credits

MyUCLA Workspace is independently maintained by
[comet-ctrl](https://github.com/comet-ctrl), with contributions recorded in the
Git history. Product direction centers on a customizable workspace inside
MyUCLA Class Planner: dockable panels, course browsing, schedule visibility,
layout presets and appearance preferences.

## Origins

This project derives from [Better MyUCLA](https://github.com/Astro-wen/better-myucla-planner),
created by Aaron Wen (Astro-wen). Its original reordering tools and other
foundational code remain part of this project. The complete transferred Git
ancestry, original MIT license and copyright notice are preserved.

Contributor work includes Derrick2007's course tools, viewport and dark-mode
improvements, merged through PR #2 in the historical repository. Git history
is the authoritative record of individual authorship.

## Identity and dependencies

The pane icon in `public/icons/workspace.svg` was created for MyUCLA Workspace
and is distributed under this project's MIT license. It uses no UCLA logo.
Build and test dependencies are listed in `package.json` and retain their own
licenses. The extension does not bundle a separate course-data service.

MyUCLA Workspace is unofficial and is not affiliated with or endorsed by UCLA.
MyUCLA and the original website remain UCLA's services.
