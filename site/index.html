Install or update

Current source: v0.19.5. This build is available from source and is not on the Chrome Web Store. A new branded release ZIP has not been published.

With Node.js and Git installed, build the extension:

git clone https://github.com/comet-ctrl/myucla-workspace.git
cd myucla-workspace
npm ci
npm run build
  1. Keep this folder somewhere permanent.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the generated dist folder.
  4. Open Class Planner, then enable Workspace layout in the MyUCLA Workspace popup.

Already using Better MyUCLA? Replace the files in the same dist folder Chrome loads, reload the extension, then refresh Class Planner. Existing preference keys are retained. Keep one installed copy.

Historical builds remain in the previous repository. They do not include all current changes.

Built around the planner you use

Original search fields, section controls, plan actions and the calendar remain UCLA's. The extension organizes their display. Native loading steps still apply, and you can restore the original layout.

No project server, telemetry or background seat polling. This extension does not automate enrollment or read grades or DARS. Read the privacy policy.

The preview uses fictional courses and approximates some native workflows. It is a design preview, not an account connection or a guarantee of live-site compatibility.
